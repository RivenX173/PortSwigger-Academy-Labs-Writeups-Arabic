# [Clickjacking with a frame buster script](https://portswigger.net/web-security/clickjacking/lab-frame-buster-script)

## **`الهدف`**
قم بعمل كود `HTML` يُحيط `frames` بصفحة الحساب `account page` ويخدع المستخدم لتغيير بريده الإلكتروني.
## **`خطوات الحل`**
سنقوم بتسجيل الدخول إلى حساب `wiener:peter` ثم نقوم بتجربة الـ `Pre-filled Values` حيث سنجرب فتح رابط اللاب ولكن بإضافة البريد الإلكتروني في نهايته كـ `Parameter`كالتالي: 
```URL
https://0a6c001e04a0a0de811116a600f100ed.web-security-academy.net/my-account?email=test.est@king.com
```
وسنجد أن الصفحة عندما تظهر يكون البريد مكتوب بشكل تلقائي داخل حقل `Email` لذلك سنقوم بإستعمال أداة **[Clickbandit](https://portswigger.net/burp/documentation/desktop/tools/clickbandit)** لإنشاء كود `HTML` لتغيير البريد الإلكتروني، ولكن سنقوم بتفعيل خاصية `Sandbox iframe?` وسنكتب داخل الحقل `allow-forms` فقط.
